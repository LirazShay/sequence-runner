# Backlog

This directory is the durable backlog for `sequence-runner`.

Each backlog item lives in its own Markdown document so the task can be discussed, refined, implemented, and reviewed independently.

## Conventions

- One task per Markdown file.
- File names use a stable numeric prefix: `NNN-short-task-name.md`.
- Keep task documents focused on the desired outcome, constraints, and acceptance criteria.
- Implementation details may remain open until the task is actively worked on.
- When a task is materially refined, update its document instead of relying on chat history.
